# Geant4 Simulation

A simple Geant4 project that I'm building while learning Geant4 and particle simulations.

This project is mainly based on the Geant4 tutorials by **Physics Matters** on YouTube. I'm using it to understand how Geant4 works and to experiment with detector geometry, materials, particle generation and sensitive detectors.

## What is in this project?

- Air world
- Aerogel radiator
- 100 × 100 detector array
- Sensitive detector
- Particle generator
- Geant4 visualization
- Macro files for running the simulation
